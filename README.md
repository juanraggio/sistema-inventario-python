# Sistema de Inventario en Python

Aplicación de escritorio para la gestión de productos, desarrollada con Python, Tkinter y SQLite.

## Descripción

Este proyecto consiste en un sistema de gestión de inventario que permite administrar productos mediante una interfaz gráfica intuitiva.

El objetivo es facilitar el registro, la actualización, la eliminación y la consulta de productos, utilizando una base de datos SQLite para almacenar la información.

## Funcionalidades

- **Alta de productos:** permite registrar nuevos productos.
- **Modificación:** permite actualizar la información de productos existentes.
- **Eliminación:** permite eliminar productos del inventario.
- **Consulta:** permite visualizar los productos registrados.
- **Persistencia de datos:** almacenamiento mediante SQLite.

## Tecnologías utilizadas

- Python 3
- Tkinter – Interfaz gráfica.
- SQLite – Base de datos relacional.

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/juanraggio/sistema-inventario-python.git
   ```

2. Ingresar a la carpeta:

   ```bash
   cd sistema-inventario-python
   ```

3. Ejecutar la aplicación:

   ```bash
   python sistema_productos.py
   ```
